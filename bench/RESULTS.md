# Benchmark log

Generated by `evalbench summarize` from the JSON records in `bench/runs/`. Every row is one measured pass;
the record file holds the full setup (host, commit, flags, executor config). Do not edit by hand.

Columns: jobs/min counts every job that reached a terminal state (including cache hits) over the run's wall time.
Attempt latency runs from lease grant to result report on the coordinator clock; overhead is attempt latency
minus the executor time the worker measured (gRPC, worker scheduling, Postgres). Cache saved is cached jobs / total jobs.
